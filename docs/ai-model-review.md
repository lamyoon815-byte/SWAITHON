# CLIP-Adapter 평가 검토

- 확인일: 2026-11-11 (한국 시간)
- 대상: `origin/feature/ai-finetune`, 커밋 `84f2d76`
- 방법: 브랜치 소스를 임시 디렉터리에 추출하여 테스트 및 평가 코드 검토. 현재 develop과 실행 중인 Expo는 변경하지 않음.

## 결론

등록 작품 검색을 개선할 합리적인 구현이다. 다만 가중치와 실제 촬영 평가 데이터가 없어, 공유된 Top-1 97.0%, Top-3 100%, 평균 0.54초를 독립 재현하지 못했다. 현재 결과는 코드 검토 및 자동 테스트 결과이며, 모델 정확도 측정 결과가 아니다.

## 직접 확인한 결과

- 학습 목록: 고유 작품 ID 400개. 코드에 정의된 제외 작품 ID 및 제외 제목 키워드와 겹치는 항목은 0개. 이미지 중복이나 다른 인쇄본까지 전부 배제되었다는 증거는 아님.
- 기본 증강 설정: 작품당 변형 16장. 기본 15% 분리 시 학습 340점, 검증 60점이며 작품 단위로 먼저 분리하므로 같은 작품의 증강본이 두 집합에 섞이지 않음. 실제 학습 실행 수량은 학습 보고서가 필요함.
- CLIP 본체의 임베딩을 미리 계산하고 어댑터만 학습. 검증 손실 기준 조기 종료, 잔차 구조, 가중치 감쇠 사용.
- 브랜치 전체 자동 테스트: 80개 중 79개 통과, 1개 오류. 오류는 색각 검사판 생성 시 굵은 글꼴을 찾지 못하는 로컬 환경 문제(`test_ai_calibration.PlateTests`). 인식 정확도 실패를 뜻하지 않음.
- 로컬 및 브랜치에 `clip-adapter.npz`, 실제 평가 촬영본, `train_report.json`, 평가 `report.json`이 없음.

## 평가상 보완할 점

1. **미등록 사진의 교차 검증 그룹** — `evaluation.py:67`은 미등록 사진을 작품 ID 대신 파일명 stem으로 묶는다. 같은 미등록 작품을 다른 이름으로 여러 번 촬영하면 기준값 선정 집합과 검증 집합에 나뉠 수 있다. 실제 발생 여부는 촬영본 목록 없이는 확인 불가. 미등록 작품도 작품 ID로, 비작품은 촬영 장면/세션으로 묶어야 한다.
2. **바로 이동 기준의 비작품 누락** — `choose_high_threshold()`는 등록 오답과 미등록 작품만 고려하며 비작품은 제외한다. `decision.py:29`는 작품 판별보다 검색 점수를 우선한다. 점수 0.60, 작품 판별값 0.01, 공유된 기준값을 입력하면 `show_artwork`가 반환되는 것을 재현했다. 실제 비작품이 이런 점수를 내는지는 추가 촬영 평가가 필요하다.
3. **속도 측정 범위** — `evaluation.py:288`의 시간은 정규화·CLIP·작품 판별·검색만 포함한다. HTTP 업로드, API 품질 검사, ORB/RANSAC 위치 추정, 동시 요청 대기는 제외한다. 평균 0.54초를 API 전체 응답 시간으로 해석하면 안 된다.
4. **작은 미등록 표본** — 공유된 미등록 결과는 5장 중 2장 오매칭(40%)이다. 후보 확인과 잘못된 자동 이동은 구분하여 집계해야 한다. 같은 화가·화풍의 미등록 작품을 늘리고, 별도 촬영 세트에서 확정한 기준값을 평가해야 한다.
5. **과적합 단정 불가** — 학습/검증 Top-1 차이 0%만으로 과적합 부재를 증명할 수 없다. 두 지표는 합성 증강 이미지의 검색 성능이며 검증 집합은 조기 종료와 alpha 선택에도 사용된다. 최종 배포 설정의 성능은 별도 실제 촬영 테스트 집합에서 확인해야 한다.
