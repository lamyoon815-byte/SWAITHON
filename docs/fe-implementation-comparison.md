# 지현님 구현 우선 적용 기록

2026-11-11. 비교 기준은 지현님 작업이 반영된 `ead8009`와 통합본 `3af80f6`입니다.
`feat/onboarding`, `feat/mypage`, `feat/mypage-correction`, `feat/viewing-history`, `feat/artwork-not-found`를 확인했습니다.

| 기능 | 통합본에서 추가·변경했던 동작 | 지현님 기준으로 적용한 동작 |
|---|---|---|
| 로그인·회원가입 | 새 인증 UI와 실제 인증 API 연결 | 지현님 브랜치에는 로그인 UI가 없어 비교·교체할 대상 없음. 현재 인증 유지 |
| 첫 실행 | 소개 완료 전 다른 화면도 진입 제한 | 로그인 후 첫 홈 진입에서만 `FirstLaunch`가 소개로 보냄. 직접 연 작품 등은 소개로 가로채지 않음 |
| 마이페이지 | 상단 이름·이메일·로그아웃 카드 추가 | 상단 계정 카드를 제거하고 지현님 설정 UI 유지. 인증에 필요한 로그아웃만 하단에 배치 |
| 홈 미술관 | 미선택 시 서버 첫 미술관 자동 선택 | 자동 선택 제거. 지현님 미술관 기억 지우기를 수행하면 미선택 상태 유지 |
| 작품 촬영 | 서버 next_action에 따라 후보 확인 모달·재촬영 안내·같은 사진 AI 분석 제공 | 지현님 촬영 흐름 그대로 사용. 첫 후보가 있으면 바로 열고, 없으면 `/not-found`로 이동 |
| 해설 방식 | 전체 문장을 조회한 뒤 화면에서만 필터 | 저장된 해설 방식과 현재 선택 모드를 조회 요청에도 전달 |
| 소개·캘리브레이션·결과 UI | 통합 시 이미 지현님 화면 채택 | 지현님 화면 그대로 유지 |
| 보정 세부 조정 | 통합 시 이미 지현님 화면 채택 | 지현님 `/correction` 화면과 공용 프로필 저장소 유지 |
| 관람 기록 | 통합 시 이미 지현님 화면 채택 | 날짜별 기록과 당시 보정값 보기 유지 |

## 적용 결과의 기능 차이

- 촬영에서 후보 확인 모달과 미등록 사진의 즉시 AI 해설 버튼은 제거됩니다. 신뢰도가 medium이어도 후보가 있으면 첫 후보로 바로 이동합니다.
- 후보가 없는 촬영 결과는 지현님 실패 화면의 ‘다시 촬영하기’, ‘목록에서 고르기’로 처리합니다.
- 로그인·회원가입, 실제 작품 데이터 연결, 등록 작품의 AI 음성 해설 생성, 서버 색·윤곽선 보정은 지현님 구현에 대응 기능이 없어 유지합니다. mock 데이터는 복구하지 않습니다.
- 기존 기기 보정값을 지현님 공용 프로필 저장소로 이전하는 호환 코드와 관람 기록의 서버 보정 연결도 유지합니다.
- 서버 AI API와 Gemini 예산·키 설정은 변경하지 않습니다.
