# 실제 픽셀 구분 회복을 위한 보정 v2: 개발·검증 계획

이 계획은 v2의 개발 및 새로운 검증 자료의 결과를 보기 전에 고정한다.
v1의 21점 결과는 이미 관찰했으므로 21점 비교는 회귀/개발 결과로 표시한다.
v1 코드, 설정, 원자료, 실패 결과는 그대로 보존한다.

## 확인된 v1의 문제

- 대표색의 목적함수는 줄었지만 실제 픽셀 회복률은 학습에 쓴 Machado에서도 낮았다.
  밀밭/적색약: 대표색 목적값 0.4656→0.00158, 픽셀 회복률 약 3.04%.
- 63개 작품·유형 중 18개에서 대표색 사이의 혼동 쌍이 없어 원본을 그대로 반환했다.
- 모든 63개에서 색 변화 예산 축소가 발동하지 않았다. 따라서 최종 예산 제한 때문에
  색 변화가 5.73→0.70으로 감소했다고 설명하면 안 된다.
- 대표색만 평가하고 실제 픽셀 혼합 결과를 최적화하지 않은 설계를 바꾼다.

## v2의 방법

1. 현재 앱/서버의 기존 보정 A'를 출발점으로 사용한다.
2. k-means로 찾은 약 12개 대표색은 부드러운 보정 함수의 좌표로 사용한다.
   대표색에 혼동 쌍이 없다는 이유로 실제 픽셀 보정을 포기하지 않는다.
3. 실제 표본 픽셀 쌍에 대해 Machado 2009에서 사라진 색 차이를 회복하도록
   보정 함수의 계수를 최적화한다. 새로운 충돌과 원본 색 변화도 제한한다.
4. 별도의 고정 시드 픽셀 표본에서 Machado 기준 A'보다 이득이 있고 새 충돌이
   늘지 않는 경우에만 후보를 사용한다. 조건에 맞지 않으면 A'를 그대로 사용한다.
   이 선택은 Brettel/Viénot/Vischeck/HPE 점수를 보지 않는다.
5. 최종 실제 평균 ΔE가 A'보다 큰 후보는 원본 쪽으로 줄인 뒤 다시 자체 검증한다.
   선택 전 후보 수치와 A'로 복귀한 비율도 공개한다.

픽셀마다 군집 가중치를 반복 계산하는 비용은 33×33×33 격자의 함수와 연속 삼선형
보간으로 줄인다. 최적화도 같은 보간 함수의 픽셀 출력을 통해 계산하여 학습/적용을 맞춘다.

신경망이나 정답 라벨을 학습하는 방법은 아니다. 기존 보정 + 비지도 군집화 +
실제 픽셀 쌍 최적화이며, 그림마다 계산한다. 효과를 보장한다고 주장하지 않는다.

## 자료 분리와 평가

- 개발: 기존 21점 중 우선 밀밭(met-01), 침실(aic-02), 프로방스 농가(nga-01)에서
  학습 목표와 동작을 확인한다. 기존 21점 전체는 성능 회귀 비교용이다.
- 새 검증: 로컬 NGA 공개 회화에서 `sha256('palette-v2-final:' + object_id)`
  순서로 12점 선택. 목록/입력 해시는 개발 전에 [holdout.json](holdout.json)에 고정한다.
  이 그림들은 이전 색 보정 실험에 쓰지 않았다. 기존 작품 인식 실험의 학습 자료였다는
  사실은 구분해서 표시한다. 보정 모델의 새 그림 검증을 위한 자료다.
- 검사판: 기존 12장·세기 0.2/0.6/1.0 및 별도 새 seed 9101/9202/9303,
  숫자 61/47/82로 각 유형 1장 추가. 추가 판은 설정 고정 후에만 평가한다.
- v2 설정은 개발이 끝나면 별도 JSON에 고정한다. 새 검증 자료 결과로 설정을
  고르거나 재조정하지 않는다. 실패 시 그대로 보고하고 원자료를 유지한다.
- 관찰자 모델은 Brettel/Viénot/Vischeck/HPE, severity 1.0. 보정 세기와 구분한다.
  Viénot 청색약 및 HPE의 한계는 v1과 동일하게 표시한다.
- 회복률 정의, 픽셀 쌍 30,000개, 평가 시드 20261113, ΔE 정의는 v1과 같다.
  회복률만을 위한 계산은 같은 600px 이미지에서 뽑은 픽셀들의 RGB에 시뮬레이션을
  적용하여 계산량을 줄인다. 점별 변환이므로 전체 이미지에서 계산한 값과 일치해야 한다.
- 기존 21점은 1000px 입력, 새 12점은 보유 원본(최대 512px)에서 평가한다.
  서로 다른 해상도 집단은 따로 보고한다. 1000px 시간은 기존 21점에서 측정한다.

## 성공 조건과 보고

- 각 집단에서 모델·유형별 micro 회복률과 단순 작품 평균, 새 충돌률을 함께 공개한다.
- 새 자료 12점에서 네 모델 각각의 전체 micro 회복률이 A'보다 높고,
  각 유형의 micro 회복률은 A' 이상이어야 새 그림 개선 근거로 인정한다.
- 기존 21점에서도 네 모델 전체 회복률이 높고 유형별 회복률이 A' 이상이어야 한다.
- 모든 작품·유형에서 실제 평균 색 변화는 A' 이하(+1e-6 ΔE 허용).
- 각 검사판 모델·유형·세기 평균 대비는 A' 이상(-0.001 ΔE 허용).
- 기존 1000px 작품의 최대 처리 시간 3초 기준은 그대로 보고한다. 넘으면
  정확도 개선과 별개로 시간 조건 실패를 표시한다. 다른 실패도 숨기지 않는다.
- 검사판 숫자 정답률이나 실제 사용자 정확도로 부르지 않는다.
- 앱/배포 연결은 이 실험의 결과와 미리보기·세기 일치 여부가 검증된 뒤 판단한다.
