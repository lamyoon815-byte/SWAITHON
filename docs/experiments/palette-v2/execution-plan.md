# v2 계산 속도 검증 계획

v2의 정확도·색 변화·검사판 검증은 통과했으나, 기존 실행에서 63건 중 9건이 3초를 넘었다.
학습 목표, 설정값, 후보 선택, 보정 결과를 바꾸는 조정은 하지 않는다.

- A'의 `M×N×3` 거리 계산 임시 배열을 채널별 `M×N` 배열로 바꿔 메모리 부담을 줄인다.
  뺄셈/제곱/덧셈/제곱근 순서와 dtype은 유지한다. 수정 코드는 별도 실험 모듈에 둔다.
- NumPy/BLAS 및 OpenCV를 단일 스레드로 실행하는 별도 작업 프로세스를 사용한다.
  입력 이미지나 평가 기준을 줄여 시간을 맞추지 않는다.
- 기존 21점의 1000px, 세 유형 전체 63건을 다시 측정한다. 3초 기준을 그대로 둔다.
- 기존 A'와 최적화 A'의 픽셀 배열을 모든 33점에서 직접 비교한다.
- 빠른 실행의 모든 모델별 픽셀 쌍 지표와 ΔE를 저장된 v2 결과와 대조한다.
- 세 개발 사례는 기존 함수와 빠른 함수의 전체 결과 픽셀도 직접 비교한다.
- 단일 실행 시간 전체를 보존하고 최대값을 공개한다. 실패 사례를 제외하지 않는다.
- 새 모델/데이터로 추가 학습하는 것이 아니라 수치 결과를 유지하는 실행 최적화다.
