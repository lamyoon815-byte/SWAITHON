## 왜 v1을 바꿨나

v1은 대표색 목적값을 줄여도 실제 픽셀 쌍을 회복하지 못했다. v2는 실제 픽셀 출력을 통해
최적화하고 A'를 출발점으로 보존한다. 자체 검증에 실패하면 A'로 돌아간다.
자체 검증은 Machado 기준이므로, 다른 관찰자 모델에서도 개별 그림의 무하락을 보장하지는 않는다.

## 결과를 유지하는 실행 최적화 검증

[실행 검증 상세](execution-report.md)에 원자료와 재현 명령을 정리했다.
33점×3유형의 A' 픽셀은 99건 전부 원래 계산과 동일했고, v2의 396개 모델별
픽셀 쌍 지표 및 평균 색 변화도 저장된 결과와 모두 일치했다.
별도로 비교한 세 사례의 최종 전체 픽셀도 동일했다.

메모리를 줄이고 단일 스레드로 실행한 경로의 1000px 중앙값은 2.521초,
최대는 4.204초였으며 63건 중 22건이 3초를 넘었다.
기본 v2 실행은 중앙값 2.073초, 최대 5.182초, 3초 초과 9건이었다.
최댓값은 줄었지만 중앙값과 초과 건수는 늘어 **일괄적인 속도 향상으로 판정하지 않는다**.
어느 경로도 최대 3초 조건을 통과하지 못했다. 앱 배포 설정은 바꾸지 않았다.

## 구현 검증과 발표 문장

색 보정·검사판·v1·v2·수치 미분·평가 동등성·실행 동등성 테스트 총 48개 통과.
새 Python 파일의 편집기 진단 오류는 없었다.

“k-means 비지도 군집화로 그림의 대표색을 찾고, 기존 보정에서 실제 픽셀 사이의 색 차이가
더 잘 구분되도록 최적화했습니다. 최적화에 쓰지 않은 Brettel 모델 기준으로 기존 21점의
