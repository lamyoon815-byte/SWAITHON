# 국소 색 변화 제한과 3초 처리 검증: 개발 전 계획

v2의 회복률 향상은 보존 기록으로 남긴다. v2의 원 코드, 설정, 입력과 수치는 변경하지 않는다.
이번 실험은 평균뿐 아니라 각 픽셀의 원본 대비 ΔE76도 기존 A' 이하로 제한한다.
이 조건은 자연스러움 전체를 증명하지 않지만, 작은 영역에 색 변화가 집중되던 원인을 제한한다.

## 개발과 최종 검증 분리

- 개발 자료: 기존 작품 21점과 이미 평가한 v2 추가 작품 12점. v3에서는 모두 개발·회귀 자료다.
- 새 자료: 로컬 Painting 중 v2 추가 12점을 제외하고 `sha256(palette-v3-final: + object_id)`
  순서의 처음 12점. 개발 전에 파일 해시를 기록하고, 설정 고정 후 한 번만 최종 평가한다.
- 개발 중 후보 조정·선택에는 Machado만 사용한다. Brettel·Viénot·Vischeck·HPE는 고정 후 평가한다.
- 처리 시간은 최대 1000px RGB 배열 입력의 A' 계산, 군집화, 최적화, 전체 적용과 최종 검증을 포함한다.
  파일 읽기/JPEG 저장/최종 평가를 제외한다. 512px 원본의 시간과 1000px 시간을 분리한다.
  단일 초기화 뒤 전체 입력을 측정하고, 가장 느린 1000px 5건은 2회 추가 측정한다.
  3초를 초과한 경우를 그대로 공개하며, 시간 제한으로 회복률 평가를 건너뛰지 않는다.

## 구현 방향

- k-means 12색의 부드러운 함수를 유지한다. 이동량은 연속 CIELAB에서 최적화한다.
- 각 픽셀의 이동을 해당 픽셀의 A' 색 변화 반경 안으로 투영한다. 실제 출력의 gamut clipping과
  평가용 Lab 변환 뒤에도 조건을 다시 검사하고, 초과 픽셀을 줄인다. 최종 후보는 Machado로 다시 검사한다.
- 전체 해상도에서 학습용 감마 변환을 반복하지 않고 필요한 픽셀만 추출한다.
- LUT 보간의 메모리 이동을 줄이고 A' 거리 계산을 작은 블록으로 처리한다.
- A'보다 자체 회복 쌍이 늘고 새 충돌이 늘지 않으며, 원래 손실된 쌍의 평균 대비도
  A'보다 낮아지지 않는 후보만 선택한다. 원본 검증 픽셀을 큰 색 그룹 3개로 묶어,
  헷갈리던 그룹의 평균 시뮬레이션 색 대비도 A' 이상 유지하는지 확인한다.
  이는 숫자/배경 정답이나 작품의 의미를 사용하지 않는 일반적인 후보 탈락 조건이다.
  조건을 만족하지 못하면 정확히 A'를 반환한다.
- 개발 자료에서 64회→48회 반복을 비교해 처리 시간을 줄였다. 전체 적용 전에 검증 표본에
  실제 픽셀 보정과 국소 제한을 적용해 탈락 후보를 먼저 제거한다. 최종 전체 출력도 다시 검증한다.
- 전체 적용 및 A'의 대표색 거리 계산에는 C 커널을 사용한다. 65,537칸 보간표로 연속 색 변환을
  계산하며 수치 오차와 부드러운 경사에서의 불연속 여부를 검사한다. 컴파일·라이브러리 초기화는
  측정 전 수행하고, 작업 프로세스는 OpenCV·BLAS 1스레드로 고정한다. 앱 프로세스는 변경하지 않는다.
- 반복 최적화의 목적값과 해석적 미분도 double 정밀도 C 계산으로 묶는다. NumPy 기준 목적값·미분,
  수치 미분과 모두 대조한다. 학습 목표나 후보 선택에 평가 모델을 추가하지 않는다.
- 앱의 기존 보정과 라우트는 이번 검증 동안 유지한다.

## 통과 조건

1. 개발·회귀 집단과 새 12점 각각의 네 평가 모델에서 전체 회복률 상승, 유형별 하락 없음.
2. 모든 입력의 평균 ΔE와 **모든 픽셀의 ΔE**가 A' 이하(수치 허용 오차 1e-6).
3. v2와 같은 기존/추가 검사판의 모델·유형·세기별 평균 숫자 대비 하락 없음(ΔE 허용 오차 .001).
   숫자 대비는 실제 숫자 정답률과 구분한다.
4. 1000px 전체 처리 및 느린 사례 반복 측정에서 관측 최대 3초 이하.
5. 기존 문제 사례인 장미/청색약과 아기 초상/녹색약을 원본 해상도에서 잘라 비교한다.
   각 픽셀의 ΔE, 95·99백분위, 어두운/중성 영역, 부드러운 색 경사에서 띠·얼룩을 확인한다.
   시각 검사는 소수 사례의 개발자 점검이며 실제 사용자 평가는 별도로 명시한다.

개별 그림·유형·모델의 하락 수와 A' 복귀 수, 추가 국소 제한 때문에 v2 대비 줄어든 회복률도 공개한다.
시뮬레이션 회복률을 실제 사용자 정확도나 신경망 학습 정확도로 부르지 않는다.
